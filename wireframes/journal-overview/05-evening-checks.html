Notes — why the move
  • The panel's own rationale is sound and documented: it is the only authoring surface in a read-only journal, and it is pull because scheduled Telegram nudges were answered 2/44 while post-pomodoro buttons were answered 10/10. None of that argues it must sit on Overview.
  • It felt unfinished on Overview because it is a form in the middle of a readout — three different input types (checkbox / 1–5 scale / free text) plus an add-item box, in a generic collapsible. In a reflection flow it is the main event and reads as intentional.
  • Cost of the move: the checks lose their daily incidental impression. Mitigation — Overview's routine metric ("Routine 1/4") can carry an unanswered-checks count, linking here. Worth deciding.
  • Alternative if you disagree: keep it on Overview but give it real identity — full-width, its own heading treatment, and only unanswered items shown. Cheaper; less coherent.
