Pipeline funnel

Second attempt, built to the sketch. One continuous vessel top to bottom — the narrowing is the attrition. Each project keeps its colour, so you watch which ones get cut at which gate. Controls sit level with the phase they govern. Real production numbers, tonight.

Width is √count, not count — at true scale the 62 that survive project scope would be 5% of the mouth and the rest invisible. Exact numbers stay in the left column; the shape carries proportion only.
