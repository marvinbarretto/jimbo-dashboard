One dominant element per card — the title. Project moved from a full-width bar to a 3px left stripe + small `/proj` link. Picker tucked into a hover-revealed `⋯` button. Rationale collapsed to one line; click to expand. Primary action (decompose) dominates; archive/delete shrink to icon buttons. Type glyph in front of #seq. Priority as vertical bars, not a chip. Visual language

Left edge stripe
Project hue. Width fixed at 3px. Tip warms toward amber when card is stuck/hot.
Type glyph
✓ task · 📎 reference · 💡 idea · ◆ epic · ? question
Priority bars
Four 2px verticals. P0 = all four, red. P1 = three, amber. P2 = two. P3 = one.
Genesis chip
Small rectangular, monochrome. Distinct from the round actor avatar. Kinds: manual, ↳ #N (auto), github, external.
Owner avatar
Round, 16px in kanban. Lives bottom-right of meta row. The only round element on the card — eye trains on it.
Callout
Collapsed by default to one line. Border colour encodes kind (accent=rationale, green=result, red=error).
Stuck age
Plain text when fresh; pill with warning tint once `daysInColumn` exceeds threshold.
Stale desaturation
Title opacity ramps down 0→25% as `--urgency` ramps 0→1. Old cards look tired without taking extra space.
