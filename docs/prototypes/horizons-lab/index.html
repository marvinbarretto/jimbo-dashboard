Horizons Lab · angles

Same Priorities + Ambient data (real content, real ages) rendered five different ways. The brief: see the time-immediate stuff at a glance, and see the long tail — and how long it's been sitting there — without it turning into a wall of text. Click to load.

01
Focus & Table
Tiny "touched recently" strip up top; everything else in one dense, sortable table with age as a real column.
 02
Orbit
Radial chart — distance from centre is staleness, angle is horizon bucket. The cluster's shape tells the story before you read anything.
 03
Staleness Heatmap
Kanban-shaped, but text opacity fades with age — stale items visibly recede without needing a chart at all.
 04
Collapsed Digest
Everything closed by default — one line per bucket (freshest item + stale% flag). True hide/show; expand only what you want.
 05
Age Histogram
Zooms all the way out — a stacked bar chart of the whole collection by age band. Click a bar to drill into what's in it.
Evaluate against:
· What's time-immediate is obvious in <1s
· The long tail is scannable, not a wall of text
· Staleness ("how long has this sat here") is visible, not something you infer
· Still feels like the same product (mono chrome, sans prose — see app-ui-prose)
